Dynamic Programming: 2D State Explosion Severity: High
62% failure rate on large N • O(N*M) auxiliary space explosion

Solutions frequently exceed heap recursion limits or hit Time Limit Exceeded (TLE) due to unoptimized 2D memoization tables instead of space-compressed 1D rolling state vectors.

Recommended Fix: State rolling with modular index `[i % 2]` View AST Rule →
Quadratic String Concatenation Severity: Medium
44% suboptimal runs in Python/Java • O(N²) reallocations

Repeated string concatenation inside tight loop structures causing hidden O(N²) memory reallocation penalties instead of using StringBuilder or dynamic list joining.

Recommended Fix: Pre-allocated buffer or `"".join(chunks)` View AST Rule →
Unbounded Nested Loops (Brute Force) Severity: Medium
38% TLE occurrences • Combinatorial Search Overhead

Over-reliance on O(N³) combinatorial nested scans before exploring two-pointer monotonic window reductions, sliding boundaries, or hash index lookup dictionaries.
