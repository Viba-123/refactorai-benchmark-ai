Given a string s, return the longest palindromic substring in s.

A string is palindromic if it reads the same forward and backward. In cases with multiple valid substrings of identical maximum length, any such substring will be accepted.

Example 1
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
Example 2
Input: s = "cbbd"
Output: "bb"

rule Constraints

  • 1 <= s.length <= 1000
  • s consists of only lowercase and uppercase English letters.
How can we reuse previously computed palindromes? A palindrome mirrors around its center. There are 2N - 1 such centers (both single character and inter-character gaps). You can expand outwards from each center in O(N) time.

# RefactorAI Engine: Optimal Expand Around Center class Solution: def longestPalindrome(self, s: str) -> str: if not s or len(s) == 1: return s start, end = 0, 0 def expand_around_center(left: int, right: int) -> int: while left >= 0 and right < len(s) and s[left] == s[right]: left -= 1 right += 1 return right - left - 1 for i in range(len(s)): # Odd length palindrome center len1 = expand_around_center(i, i) # Even length palindrome center len2 = expand_around_center(i, i + 1) max_len = max(len1, len2) if max_len > (end - start): start = i - (max_len - 1) // 2 end = i + max_len // 2 return s[start : end + 1]
